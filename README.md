# gz-theme

Dark themes for Gazelle-based trackers, based on the ewolbash "opsdark" styles
with the site logo swapped in.

- `dg-green.css` — green accent
- `dg-red.css` — red accent

**Use:** paste the file's raw URL into *Settings → Appearance → External stylesheet URL*,
or load with the [Stylus](https://add0n.com/stylus.html) extension.
